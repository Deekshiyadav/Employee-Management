# Employee Management & Reporting System (SQL)

## Project Overview
This project is a SQL-based Employee Management and Reporting System designed to manage employee and department data and generate meaningful business reports.

## Technologies Used
- SQL
- MySQL
- Power BI (for data visualization)

## Database Design
### Tables:
- Employee (emp_id, emp_name, dept_id, salary, hire_date)
- Department (dept_id, dept_name)

## Key Features
- Employee and department data management
- Department-wise salary analysis
- Highest-paid employee identification
- Use of joins, subqueries, aggregate functions, and views

## SQL Concepts Used
- CREATE, INSERT, SELECT
- JOIN (INNER JOIN)
- GROUP BY, HAVING
- Subqueries
- Views

## Power BI Integration
- Connected MySQL database to Power BI
- Created bar charts and pie charts for salary and employee distribution
- Built simple dashboards for reporting

## How to Run
1. Import the SQL script into MySQL
2. Execute the queries
3. Connect the database to Power BI for visualization
